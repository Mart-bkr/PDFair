# PDF to Markdown Conversion for WOO documents

This project provides tools to convert WOO PDF documents into structured Markdown using DeepDoctection. It includes modules for layout-aware conversion, evaluation via n-gram comparison with `pdf2text`, and basic visualization of the output and errors.

## Installation

Installation instructions can be found in:

- [installation.md](./installation.md) — step-by-step setup guide  
- [`environment.yml`](./environment.yml) — for setting up a conda environment

## Project Structure

- **PDFair/** — Contains separate Python modules for PDF processing and analysis  
- **Results/** — Stores previously generated output and evaluation results  
- **Tutorials/** — Includes example notebooks and additional resources to get started
